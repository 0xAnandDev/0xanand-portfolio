Project Overview

DecentroPay is a high-performance decentralized peer-to-peer payment application built specifically to leverage Polygon's Layer 2 scaling infrastructure. Integrated seamlessly with MetaMask, the application enables instantaneous cryptocurrency transfers, digital invoices, and multi-token processing with near-zero latency.

Tech Stack

  • Solidity
  • React
  • Web3.js
  • Polygon
  • MetaMask
  • L2 Scaling
  • Vercel

Key Features

  • L2 Fast Transfers: Immediate crypto transfers on Polygon Amoy with transaction validation.
  • DApp Wallet Connection: Smooth MetaMask integration using Web3.js for authentication.
  • Secure Ledger: Instant ledger listing transaction history with direct linkouts to Polygonscan block proofs.
  • Gas Efficiency: Reduced processing costs by 90% versus mainnet Ethereum operations.

Security & Transaction Verification

  • Cryptographic Signatures: Secures and validates sender parameters for payment authorizations.
  • Multi-Network Safeguards: Prevents operations if connected to incorrect chain IDs.
  • Non-Reentrant Withdrawals: Implements secure transfer checks before state adjustments.

Challenges & Solutions

Polygon Gas Fluctuations & Transaction Reverts

Challenge: Occasional Polygon network congestion caused gas fee spike failures, resulting in hanging states or transactions reverting midway without releasing locked user funds.
Solution: Formulated strict Web3 fallback mechanisms with dynamic gas estimation. Added client-side monitoring that recalculates gas fees on-the-fly and implements atomic transaction pathways that automatically revert states safely according to smart contract protocol invariants.

Incentive Distribution & Auto-Debiting for Miners

Challenge: Requiring users to maintain native POL/MATIC tokens to pay miners/relayers for basic incentive withdrawals created a major friction point.
Solution: Implemented a meta-transaction relayer standard where the contract supports delegated signatures. The contract automatically debits transaction fees from the incentive payload itself to pay miners directly, removing the need for pre-funded native wallet balances.
