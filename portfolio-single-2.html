Project Overview

AagesLend is a production-grade decentralized lending protocol engineered to enable secure, non-custodial capital markets on EVM-compatible chains. The protocol implements over-collateralized lending vaults, dynamic interest rate curves, robust role-based access control (RBAC), and a bulletproof health factor liquidation engine to safeguard depositors' liquidity.

Tech Stack

  • React

Key Features

  • Collateral Management: Direct on-chain management of token collateral with safe asset-to-debt ratios.
  • Borrowing Mechanics: Dynamic borrow capacity calculations based on real-time price feeds.
  • DeFi Dashboard: Complete React-based client dashboard displaying protocol insights.
  • Wallet Integration: Secure Ethers.js implementation with MetaMask connection and network checks.

Security & Permission Features

  • Role-Based Access Control: Uses OpenZeppelin AccessControl to enforce Admin/Lender/Borrower separation.
  • Least-Privilege Roles: Restricts operational functions to prevent unauthorized administration.
  • Health Factor Calculations: Continuously monitors loan-to-value status on-chain.

Challenges & Solutions

Liquidation Calculations & Bad Debt Mitigation

Challenge: Executing real-time liquidation computations on-chain is vulnerable to latency. If the liquidation formula runs slowly when LTV falls under 1.0, bad debt accumulation can occur, causing the protocol to crash under high volatility.
Solution: Engineered a highly optimized math engine using fixed-point decimals. The liquidation engine relies on immediate, gas-optimized checks that trigger third-party bot execution pathways at exact LTV boundaries, halting bad debt cascades instantly.

Sub-100k Gas Execution Constraints

Challenge: Multi-tiered borrow/repay transactions exceeded standard gas thresholds, creating a poor user experience.
Solution: Achieved sub-100k gas execution via storage packing (wrapping uint96 vars into a single 256-bit slot), inline Yul assembly for 15% bytecode size reduction, and batching transactions to cut overhead by 40%.
