Project Overview

BlockPulse AI is a full-stack, real-time wallet threat-monitoring platform built for HACKHAZARDS '26. It continuously polls registered Ethereum Sepolia wallets, runs every new on-chain event through a rule-based detection engine, turns detections into a weighted 0–100 threat score with a plain-English AI summary, and pushes High/Critical alerts straight to email and Telegram — with a full audit trail (risk history, alerts, PDF reports) behind it. The core pipeline: Monitor → Detect → Score → Explain → Notify → Report.

Tech Stack

  • NestJS
  • TypeScript
  • React 19
  • PostgreSQL
  • Prisma
  • Ethers.js
  • TanStack Router

Key Features

  • 5-Detector Risk Engine: Flags unlimited approvals, ownership changes, large transfers, new contract interactions, and wallet inactivity, producing a weighted 0–100 risk score.
  • AI Security Assistant: Per-wallet chat grounded in that wallet's real score, alerts, and profile — answers questions using actual on-chain data, not canned text.
  • Automated Alerting: Email (SMTP/nodemailer) and Telegram Bot API notifications fire automatically on every High/Critical alert.
  • On-Demand PDF Reports: Downloadable, per-wallet security reports generated server-side with pdfkit.
  • Live Monitoring Dashboard: Real-time scan phase, next-scan countdown, and aggregated protection status across all wallets.

Security & Permission Features

  • Rotating JWT Refresh Tokens: 15-minute access tokens with 7-day httpOnly, sameSite refresh tokens, hashed server-side and rotated on every use.
  • Per-User Authorization: Every wallet-scoped endpoint re-verifies wallet ownership against the authenticated user before returning data.
  • Hardened API Surface: bcrypt password hashing, global input validation (whitelist/transform DTOs), rate limiting, and Helmet transport hardening.

Challenges & Solutions

Continuous Chain Monitoring Without Re-Scanning Everything

Challenge: Polling Ethereum Sepolia for every registered wallet on every tick risks unbounded catch-up scans and duplicate event processing as the wallet count grows.
Solution: Built an incremental scanner that persists lastProcessedBlock per wallet and scans only new blocks each 20-second tick, capped at 50 blocks per run to bound worst-case catch-up, with detections deduped before becoming alerts.

Explainable Risk Scoring Without a Black-Box Model

Challenge: Users needed to trust and understand why a wallet was flagged, which rules out an opaque ML risk score as the primary signal.
Solution: Implemented a deterministic, weighted rule-based RiskScoreEngine with a repeated-event multiplier and documented scoring model, then layered an AIProvider interface on top for plain-English explanations and Q&A — swappable for a real LLM later without touching any caller.
