Github 0xAnandDev/Solvigil
Visit Live solvigil-scanner.vercel.app

Solvigil is an automated smart contract vulnerability detection platform designed to protect Web3 decentralized applications before deployment. By utilizing rigorous Abstract Syntax Tree (AST) parsing techniques, Solvigil walks through Solidity code blocks to isolate reentrancy bugs, access control vulnerabilities, unchecked return values, and potential Denial of Service (DoS) attack vectors.

The system compiles smart contracts in real-time, extracts logical node representations, and applies precise pattern matching to highlight critical security anomalies. Featuring a modern, high-performance UI constructed with React and a robust Node.js backend scanner, Solvigil empowers blockchain developers to implement early pre-audits and deploy secure Web3 solutions confidently.
